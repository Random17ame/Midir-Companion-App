# Music Lab and Melodic Puppeteer

**Applies to:** Midir Companion 0.3.11i.

**Scope:** Current implemented behavior only. Historical changes are recorded in [`CHANGELOG.md`](../CHANGELOG.md).

## Music tools

- The Music Buff Effect Calculator models input stats and bonuses. A separate playful “Rate Isn’t a Lie” performance activity is displayed on the same page. The calculator and the performance simulator work on phones. Assign Bard skills by dragging a tile onto a hotkey slot or tapping a skill then a slot; drag to rearrange, long-press to clear during setup, and tap an assigned hotkey during a performance to cast. The on-slot cooldown display and desktop keyboard inputs use the same performance engine.
- Calculated and simulated values are training estimates and should not be presented as verified in-game buff rates.

## Rhythm practice

- Melodic Puppeteer Cutting Chorus practice works on desktop using separate mouse aiming and keyboard activation, and has implemented touch-aim pointer plus distinct skill trigger buttons. The activity is accessible through the mobile Arcana hub, with separate touch aiming and skill triggers. Saved records use the Companion’s existing profile integrations.

## Cutting Chorus touch input

On touch screens, aim by dragging a finger or stylus inside the playfield and trigger timing independently with the individual Melodic Puppeteer and base puppet skill buttons below it. Dragging or tapping a note in the playfield never scores it; a note is credited only when a separate rhythm button is pressed while the aiming cursor is near it within its timing window. Distinct skill buttons allow Hard mode to enforce its existing no-repeat rules. Desktop mouse aiming plus keyboard timing remain unchanged. [1] `Companion Files/mp-rhythm.js`; [2] `Companion Files/styles.css`.

## Cutting Chorus skill trigger panel

On touch screens, the trigger panel shows Melodic Puppeteer skills and base puppet skills in a shared compact icon bank, with Cutting Chorus on its own row. Each button displays a **cooldown** based on current Rotation Highlights minimums; numbered Puppet Acts have a provisional fixed +3s penalty. Cutting Chorus retains the 4s/2s Link toggle. For base skills without a known minimum, the provisional value may be zero. Hard mode tracks the last two distinct skill inputs, and aiming and triggering remain separate touches. PC mouse-and-keyboard play is preserved. Source: `Companion Files/mp-rhythm.js`, `Companion Files/styles.css`.

## Mobile access

Cutting Chorus is available from the mobile Arcana hub. The skill trigger panel preserves separate aim and timing inputs; direct tap-to-hit is not supported. The legacy generic keyboard-only drill remains restricted on mobile. Physical-device multi-touch comfort and responsiveness still need verification. [1] `Companion Files/app.js` (`MIDIR_MOBILE_DESKTOP_ONLY`); [2] `Companion Files/mp-rhythm.js`.

## Music Calculator equipment sets and enchant/reforge editor (0.3.11i current)

**Buff Set tabs** model a complete nine-slot loadout (eight ordinary gear slots plus a Blue Echostone): Accessory 1, Accessory 2, Wings, Hat, Body, Boots, Gloves and Instrument. Each *physical item* has its own name, slot-restricted Prefix/Suffix enchant rolls and up to three independently configured reforge lines. The compact, icon-based equipment board opens an individual item editor when the user taps a slot. An item belongs to the shared equipment library, and multiple buff sets can equip the **same item ID** (including the same instrument, its upgrades, quality and special upgrades). Editing that shared item changes all sets that use it. **Make separate copy** creates an independent copy attached only to the active tab; **New item** creates an empty replacement, and the Equipped item dropdown selects an existing compatible item. The same physical accessory cannot occupy both accessory slots of a single tab. [1] `Companion Files/app.js` (`MUSIC_ENCHANT_SLOTS`, `musicGearState`, `musicGearItemSummary`, `musicBuffBind`).

Normal, Excellent and Inspiring Performance Effect reforges live on individual equipment items, rather than in an independent floating group. The reforge dropdowns use `window.MIDIR_REFORGE_TABLE` from the existing Reforge Simulator, with the simulator’s normal and limit-break caps for the selected slot; each item has at most three lines and a duplicate effect is unavailable on other lines. Special Ethereal Chiffon Wings are non-reforgeable. The center-right Blue Echostone slot supports exactly one Blue-eligible reforge and no enchants, Murias Water, grade or special upgrades. Its level is capped at the simulator’s normal Echostone roll maximum; equipment limit-break levels are not available to Echostones. For a matching-name reforge, if the Echostone level exceeds every individual equipped gear line, it replaces their sum rather than stacking with them; if not, the ordinary gear lines retain their sum. Inspiring Performance Rate is also available in the Echostone slot as an informational rate, distinct from Inspiring Performance Effect. Echostones are reusable across buff sets and can be copied independently. All existing song-specific reforges, including **March Song Walking Speed**, live in the same three-line editor; Mount Speed is no longer part of the calculator. **Enduring Melody Defense Reforge** is included (up to level 3, adding +1 base Defense per level before the existing performance multiplier). Instrument grade, special upgrade level and instrument-specific buffs travel with the physical instrument and are not editable in other slots. Song selection changes the result preview and side-by-side comparison of every named set. [1] `Companion Files/app.js` (`MUSIC_GEAR_REFORGES`, `musicBaseEffects`, `musicCalcForKey`, `musicGearCompare`).

Equipment combination effects are configured per slot, rather than in a separate global field. Supported options are **Special Ethereal Chiffon Wings** (+1 Music Buff Effect and +2 Inspiring Performance Rate; the rate is not treated as buff magnitude), **Seraphic Cantabile bangles** (Battlefield Overture +5%), and **Troubadour** hat/wig (Vivace +3%), bodywear (Battlefield Overture +3% and Enduring Melody +3%), gloves (Harvest Song +3%, Lullaby +3%) and boots (March Song +3%). Duration and Fantastic Chorus bonuses are not modeled. **Named set bonuses never stack with the same name; the highest value applies.** Equipping Seraphic bangles with Troubadour bodywear produces Battlefield Overture +5% (not +8%) plus Enduring Melody +3%. Removing Seraphic restores Troubadour Battlefield Overture +3%. Old global set values remain visibly unassigned and their Battlefield Overture effect participates in this same maximum calculation until replaced by equipment-slot selections. [1] `Companion Files/app.js` (`MUSIC_SLOT_SET_EFFECTS`, `musicGearSetStat`, `musicGearSetEffectsEditor`). Sources: supplied Mabinogi World Wiki HTML captures for the three equipment sets.

Enchant Effects defaults to the sum of equipped physical-item enchant contributions. Each item can use its automatic Prefix/Suffix subtotal or an optional **per-item manual enchant amount**, including an explicit zero; blank or **Use this item’s enchants** resets that item to automatic. A typed **overall Enchant Effects override belongs only to the selected buff set**, takes final precedence over the sum of all automatic/manual item enchant contributions, and persists until **Use equipped total** resets it to automatic mode. Per-item enchant overrides neither alter reforges, instrument upgrades nor named equipment combination bonuses. Older 0.3.11 enchant selections migrate into the initial gear items. Old flat reforge values are **kept as visibly unassigned, still-counted values** until a user chooses their original gear slot; assigning one to an item in a copied set first detaches the shared item so another set is not modified or double-counted. Legacy Mount Speed is ignored without removing unrelated saved profile data. The removed duplicate `musicKnowledgeReforge` is not counted. [1] `Companion Files/app.js` (`musicGearState`, `musicGearUnassigned`, `musicGearValue`).

**Holy Water of Murias (0.3.11c):** It is attached to each eligible physical item, not a global input. Two accessories, hat, body, boots, gloves and instrument can each contribute **+1 Music Buff Effect** (maximum automatic +7); wings and Blue Echostones are excluded. The equipment board shows the auto total and applied total. A nullable whole-set Murias override replaces the auto sum for the selected buff tab; blank or **Use slot total** returns to automatic, and an explicit zero is valid. Shared items carry their Murias status across tabs; copied physical items are independently editable. Prior saved nonzero flat Murias amounts are retained as visible **whole-set overrides** so no unknown equipment is guessed and no bonus is counted twice. The old standalone Murias field is removed from the advanced source-input panel but the historical value is preserved for migration. [1] `Companion Files/app.js` (`musicGearMuriasTotal`, `musicGearMuriasApplied`, `musicGearState`).

The calculator places its live four-stat result strip above the compact equipment slot board and keeps those results visible while scrolling the calculator. The slot modal pins an independent Normal/Excellent/Inspiring preview, including while editing its manual override. Item management/copies remain inside the modal; buff-source fields and compare/set management are collapsed by default and available on demand. The new per-item override precedence, sharing/copying and reload were checked with automated phone-sized browsers; full physical-phone interaction and real HTTPS backup/restore remain to be verified. [2] `Companion Files/styles.css`.

## Compact Cutting Chorus controls (current)

On mobile the twelve Melodic Puppeteer/puppet skill controls appear in a compact icon bank, with Cutting Chorus on its own row. The bank no longer uses a separate scrolling region. Starting practice brings the aiming field into view so the aiming field and controls can be operated together. Skill-specific cooldown indications, Hard mode and separate aiming/triggering are preserved. [2] `Companion Files/mp-rhythm.js`; [3] `Companion Files/styles.css`.

### Gear edit scroll behavior (0.3.11i)

Changing an enchant, reforge, roll, item value or equipment toggle preserves the editor scroll offset as the live preview recalculates. Numeric field focus is restored without scrolling the dialog back to the top. Switching equipment items opens the newly selected editor normally.
