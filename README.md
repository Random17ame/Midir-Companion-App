# Midir Companion

## What it is
- An offline companion app for **Mabinogi** players who use **Midir** damage-tracking exports.
- Imports Midir reports to review fights, track progress, and keep personal records.
- Provides optional practice tools for combat execution and related player skills.
- Works separately from Midir. It does not run the game, record live gameplay, or automatically improve a rotation.

## Features
- **The Vault:** Import and view Midir HTML, JSON, and supported NDJSON reports; review encounters and personal records.
- **Achievements.**
- **Rotation Lab:** Arcana skill references, customizable hotbars, Rotation Crafter, and practice tools.
- **Arcana activities:** Positioning drills, automaticity training, Oath Workshop, music calculator and stage, Pig Pursuit, Bandit Hunt, and Herb Collection / Precision Harvest.
- **Debuff Academy:** Lessons, debuff reference, flashcards, and recognition exercises.
- **Simulators:** Reforge and Erg Break, with their own fictional odds and progression.
- **Storage Chest:** Saved equipment, herbs, gold, ducats, consumables, and related simulator items.
- **Personal progress:** Practice records, milestones, and saved settings.
- **Backup/restore:** Export and import a full Companion profile, including supported training and simulator data.
- **Languages:** English, Korean, and Spanish (some descriptions remain untranslated).

## Use
1. Extract the ZIP, keeping its files and `assets` folder together.
2. Open `index.html` in Chrome or Edge. No installation, server, or internet connection is required.
3. Use **The Vault** to import Midir exports; use **Rotation Lab** or **Debuff Academy** for practice.
4. Create regular full-profile backups. Keep your original Midir export files.

## Important limits
- Data is stored in this browser; clearing browser data can erase progress. Backups are not encrypted.
- Reports are based on recorded events; missing or uncertain evidence is not treated as verified gameplay.
- Practice timings, simulated effects, and simulator probabilities are training/entertainment approximations, not verified in-game measurements.
- See `CHANGELOG.md` for version history and `SKILL-ICON-AUDIT.md` for icon coverage notes.
