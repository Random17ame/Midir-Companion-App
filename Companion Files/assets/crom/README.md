# Crom Bás Invaders — v208 visual direction

The original visual-concept sheet was a development-only reference and is excluded from distributable builds; the game uses its shipped runtime assets. The shipped v208 game draws newly detailed characters on the canvas at actual gameplay scale for reliable visibility and no additional asset loading. The player archer has a hood and prominent bow; Ronaun, Gwallgof, Un Llygadog, Cari, Wyneb, Wraith, Melci, Irusan, Glas, and Giga Glas have individually coded silhouettes. Basic firebolt-like shots are orange and Ice Spear is an elongated cyan crystal. Subsequent work can replace these procedural drawings with dedicated transparent sprite sheets.
